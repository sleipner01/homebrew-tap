# sleipner01/homebrew-tap

Homebrew formulae for my tools.

```bash
brew install sleipner01/tap/shotctl
```

## Formulae

| Formula | Description |
| --- | --- |
| [`shotctl`](https://github.com/sleipner01/shotctl) | Control macOS screenshot settings — format, location, shadow, filename prefix |

Formulae here are bumped automatically by CI in each tool's own repository
when a version tag is pushed; edit them there, not by hand.
